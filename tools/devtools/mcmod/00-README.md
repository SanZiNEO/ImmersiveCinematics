## 编辑页要点

- **改动附言**：只给审核员看，用来交代这次改了什么、为什么。
- **改动说明**：所有人可见，会出现在改动对比里。
- **验证码**：提交前必填。
- **快捷键**：`Alt + X` 自动链接；`Alt + Z` 全屏；`Ctrl + Enter` 快速提交。
- **编辑小技巧**：选中文本后拖动可保留格式移动；按住 `Ctrl` 拖动可保留格式复制。
- **参与活动**：可给词条挂活动标签（TeaCon / ModFest / ModJam 各年份）。
- 编辑表单主要字段（观测值）：主要名称、次要名称、站点名称/链接、简介、模组标签、作者与职位、CurseForge Project ID、百科分类、Wiki、捐赠方式、社交链接。
- 正文编辑器是 UEditor，带代码块、表格、图片、视频、"吐槽"（折叠）等工具。

## 对本项目的注意点

- 规范第 23 条：介绍不同版本特性**必须写具体版本号**，不能写"新版/旧版"——0.3.5 / 0.3.6 的区分要写清楚。
- 规范第 7 条：**禁止机翻与 AIGC 文本**。本项目 README 声明由 AI Agent 生成，百科正文建议人工重写，不要直接搬运。
- 规范第 9 条：不能只给站外链接（例如只写"详见 CurseForge"），必须有完整介绍。
- 命名规则第 1 条：译名只能用官方或 i18n 译名；本模组名 `Immersive Cinematics` 目前无官方中文名，主要名称应填英文原名。
- 模组关系：0.3.5 起已移除 Architectury，无第三方前置，因此「前置」一栏应留空。
- 批量导出工具最高只支持到 1.18.2，本项目为 1.20.1，**无法批量导出**；且本模组不新增物品/实体，资料面很小。
