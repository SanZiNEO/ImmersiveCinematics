# 如何批量添加资料

> 来源：MC百科「编辑帮助」弹窗 · 如何批量添加资料页签
> 抓取时间：2026-10-24

MC 百科提供了一键导出/导入 Mod 中所有物品与实体的便捷功能。

请下载下方的导出工具，导出 JSON 文件后，加编辑讨论群 **1137659736** 提交给管理，或发布至 JSON 收纳帖。

## 导出工具对比

## 版本选择优先级

在有多种版本可选的情况下，按照以下优先级只提交一个版本即可：

```
百科中现存资料的 MC 版本 > 1.16.x > 1.12.x > 1.18.x > 1.15.x > 1.14.x > 1.13.x > 1.7.x > 其他版本
```

上传的模组资料如果没有汉化，需要先找一下——有时会出现作者采纳汉化后还没来得及编译新 Mod 文件的情况，所以在 GitHub 上可能会有（实在没有汉化就按原文导出即可，切勿自己乱翻译）。

## 对本项目的适用性

Immersive Cinematics 是 1.20.1 的模组，**不在上述任何导出工具的支持版本内**（最新覆盖到 1.18.2）。因此物品/实体资料无法批量导出，只能手工添加；而本项目本身也不新增物品与实体，只有方块与命令，资料面很小。
