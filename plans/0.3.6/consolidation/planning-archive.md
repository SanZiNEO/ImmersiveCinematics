# `.planning` 归档规则

`.planning/` 是本地工作区（在 `.gitignore` 中，不提交），只放**当前活跃**的工作目录。

## 规则

1. **只放活跃工作**：`.planning/` 根下只允许出现当前活跃的任务目录、`_archive/` 与 `.active_plan`。
2. **完成即归档**：任务收口后，把整个目录移动到 `.planning/_archive/YYYY-MM-DD-<name>/`
   （按归档日期建日期目录，同一天归档的多个目录放在同一日期目录下）。
3. **`.active_plan` 只写一个目录名**：当前唯一活跃目录的名字；没有活跃工作时写 `none`。
4. **原始材料跟随任务走**：截图、分析 JSON、抓包、临时文本等属于某个任务的，随该任务目录一起移动，
   不在根目录散放。
5. **只移动、不删除**：归档是搬运，不做清理删除；确需删除时单独确认，不在归档动作里顺手删。
6. **被活跃计划引用的目录不归档**：若某目录仍被进行中的计划引用，保留原位，并在本文件「归档记录」里写明原因。
