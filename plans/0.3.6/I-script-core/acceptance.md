# I 轮验收矩阵

> 状态：未实现
> 范围：对象模型、脚本级规则/路径集合、必选时间门与运行激活、规则控制/事实接力/延迟动作、分支片段出口、实际状态过渡、次数执行与语义完成、格式清理、迁移、编辑器消费契约（按 Z）和真实机器验收
> 关联：`object-model.md`、`schema-and-types.md`、`runtime-evaluation.md`、`rule-system.md`、`loop-execution.md`、`format-cleanup.md`、`migration.md`、`../Z-editor/object-model.md`

## 一、原则

- 用真实 parser/validator/sampler/渲染探针，不用 mock 断言；数据探针输出 `OK/FAIL` 计数。
- 每个行为至少一个正向 + 一个边界/负向；格式清理/迁移要有全仓扫描。
- 迁移以可观察结果和明确的目标语义为准：保留的数学与字段行为做旧／新对照；段绑定、规则生命周期和过渡装配的明确变更单列差异，不用“完全等值”掩盖目标变化。
- 真实机器：Fabric 跑 fixture（`result=1` + 自然结束时间）；Forge 编译/加载；GL 探针不回归。
- 性能：F5 矩阵口径（600/600 per lane tier）不退化；对象采样不引入每帧分配。
- 所有验收脚本/探针进仓库；一次性脚本用完删除。
- 结构评审验证采样属性、脚本级规则定义/绑定、脚本级路径定义/绑定与运行激活的职责分离，并覆盖片段引用、目标对象/相邻关键帧寻址、局部坐标、关键帧顺序及组合关系；不以固定字段容器、强制拆分片段或强制全局片段库作为通过条件。
- 规则/路径集合的每条绑定独立验收：共用定义不得共享计时、`once`、边沿、等待或 timing；绑定身份与运行身份可区分。
- 规则控制验收区分判定等待与动作延后：实例级挂起只暂停本实例，多持有来源独立记账；判定成功、动作完成与片段完成分别验证，不以“实现了”合并。

## 二、数据模型 / schema

| # | 验收项 | 方法 | 通过标准 |
|---|---|---|---|
| M1 | 对象基本形态 | parser 读 `objects`，含 `value`/keyframes/空组/缺省 | 采样值符合 §3.4 |
| M2 | 路径唯一/未知路径 | 构造重复/未知/空段路径 | 加载期错误，信息含路径 |
| M3 | 同对象时间递增 | 重复/倒序时间 | 错误；不同对象同时间通过 |
| M4 | 非有限值 | NaN/Infinity | 解析期拒绝 |
| M5 | 超界关键帧 | `time<0`/`time>duration` | 忽略、不报错；最后一帧 in-range hold |
| M6 | 单帧/空组/缺省 | 单 keyframe、空 keyframes、无对象 | 恒值/对象值/schema 默认 |
| M7 | 插值 | linear/angle/geometric/step | 数值/角度/缩放/台阶符合定义 |
| M8 | 可空锁 | `yaw_lock`/`pitch_lock` null↔数值 | step 切换；两个非空角度最短路径 |
| M9 | 必填/默认 | required 无值/无默认；可选无默认 | required 错误；可选缺省可加载 |
| M10 | schema 一致性 | `TrackSchemas` vs 编辑器快照 vs 文档表 | 路径/类型/默认/插值集合一致 |
| M11 | `appliesTo` | OVERLAY fade/image/subtitle 错层对象 | validator 拒绝/警告按定义 |
| M12 | 旧字段 | `keyframes`、`meta.version`、`total_duration`、AUDIO 文件循环旧名、旧 clip 单份 `curve` | 错误“已移除”；旧路径按各旧段实际用法迁为明确段绑定，parser 不双读 |
| M13 | 路径集合与相邻段引用 | 同一片段两条以上路径条目、一段无路径；绑定目标位置对象/对象组中的两个相邻关键帧；相邻序列中夹入 FOV/调色关键帧；端点缺失、重排、段外独立帧 | 每条绑定只使用自己的控制点；相邻性只在目标位置节点序列内判断；无路径段正常插值；无效／悬空引用报错；不要求整片段三轴全局成组，不静默改绑；插入/重排保持明确绑定或显式重建 |
| M14 | 位置点源一致性 | `absolute`+非空 `position_origin`、`absolute+base`、`position_origin`/`position_origin_freeze`/`facing_source` 切换点、`base` 下 `facing_target`/`facing_entity` 切换点无位置关键帧、`auto` 下 `facing_target`+`facing_entity` 同时非空、`world` 下写 `facing_*` | 冲突组合错误；合法静态/动态点源组合通过；`auto` 按载荷/原点回落（实体/隐式 @p/player → entity，坐标/方块/结构 → world）；显式 `world`/`entity`/`line` 覆盖；未选中载荷警告；world 下方向源字段警告；切换点缺三轴关键帧错误 |
| M15 | 旧位置字段 | `follow`/`follow_selector`/`facing_origin`/`facing_origin_x/y/z`/`facing_origin_time`/`selector_*_follow`/`selector_*_facing_origin` | parser 报“已移除”；迁移器输出 `position_origin`/`position_origin_freeze`/`selector_*_position_origin`，旧 base 方向补 `facing_source=entity` + `facing_entity`（原点已是该实体/玩家时可省） |
| M16 | 脚本级集合归属 | 脚本含多条规则、同一规则多个绑定、多条路径；片段保持在原轨道 | 规则/路径在脚本级独立集合声明，通过引用定位片段；片段不被拆分或迁入全局资源库；`objects` 路径不含规则/路径结构 |
| M17 | 集合引用完整性 | 悬空片段引用、重复绑定身份、同一规则多入口、同一片段多条路径 | 加载期错误带引用路径；绑定身份唯一；每条路径条目只指向目标位置对象/对象组的两个相邻关键帧 |

## 三、运行时采样

| # | 验收项 | 方法 | 通过标准 |
|---|---|---|---|
| R1 | 同一 t 采样 | 多字段不同 keyframe 时间；探针记录采样 t | 所有字段用同一 `executionLocalTime` |
| R2 | 独立字段与显式绑定 | 对象 A 关键帧时间不影响无绑定的对象 B；另测已绑定路径 | B 只由自身数据求值；已声明的路径条目端点关系显式处理，不扩散为共享快照 |
| R3 | 零分配 | 连续采样 10k 帧，统计分配/GC | 稳态无每帧临时 map/字符串/装箱（允许游标缓存） |
| R4 | 静态片段 | 无 keyframes 的 CAMERA/OVERLAY/AUDIO/ADJUST | 正常出画面/声音/调色 |
| R5 | 超界不影响可用性 | 超界 keyframe 的点源解析失败 | clip 仍可用 |
| R6 | 采样器纯函数 | 同输入重复采样/seek | 结果一致；无隐藏状态 |
| R7 | 多实例 | 同脚本两个播放实例 | 采样缓冲/状态隔离 |

### 3.1 规则集合、时间门与运行控制

| # | 验收项 | 方法 | 通过标准 |
|---|---|---|---|
| Q1 | 时间门必选与 `>=` 阈值 | 规则缺外层时间门；局部时间 `<`、`==`、`>` 指定值；门前内层条件已成立 | 加载期要求外层时间门；默认门 = 本次执行局部时间 `>=` 指定时间；动作不得在门前执行；门后开始/继续判定，内层组合不能绕过时间门 |
| Q2 | 门前事件采集与动作分离 | 门前发生事件条件、门到后条件不再成立；事件有效期/匹配/消费不同 | 事件/事实采集与动作提交分开；有效提前事件不因门未满足而丢失；按原条件有效期/匹配/消费语义保留；不把状态一度为真永久锁存 |
| Q3 | 关键帧仅作时间引用 | 时间入口直接写局部秒；引用已有关键帧；片段无关键帧 | 两种入口都只确定一个时间点；不要求创建空关键帧；关键帧不被当作独立激活机制 |
| Q4 | 多入口独立 | 同一规则两个以上时间入口，较早入口先满足、较晚入口尚未到 | 各入口有独立绑定、采集窗口与运行身份；早入口不吞并晚入口；后续入口到达时仍建立自己的判定与运行态 |
| Q5 | 共用定义不共用运行态 | 同一规则定义被多个绑定、多次执行复用；`once`/计时/边沿/等待 | 计时、`once`、边沿、等待按绑定与执行隔离；复用定义不串状态；不做无界历史或跨实例事件总线 |
| Q6 | 迟到条件成立 | 第 1 秒门到条件不满足、播放未暂停，第 2 秒条件满足 | 门后条件迟到成立仍执行；不要求恰好同秒或 cross 事件；不把时间门写成仅精确时刻判定一次 |
| Q7 | 门后判定与动作分阶段 | 门后开始计时／观察条件，稍后成立或超时 | 判定成立不等于执行成立动作；计时、观察、成立与超时动作各按声明发生 |
| Q8 | 判定等待与释放 | 判定等待时保持内容位置；等待外部条件或超时释放 | 内容位置不推进；被声明为等待超时的计时能推进，不依赖未来尚未到达的入口来解除自身阻塞 |
| Q9 | 观察生命周期 | 非阻塞观察跨片段；`once:false` 观察与有限内容自然完成；停播／替换 | 时间门不是失效窗；普通观察不阻止自然完成，随实例回收；需阻止完成时显式声明等待 |
| Q10 | 多规则与事件边界 | 同一局部位置多条规则、连续多次执行、同屏其它实例 | 不漏判定、不串状态；规则重新判定不等于服务端 EVENT 重新触发；规则动作不复用 `EventKey`；EVENT 命令协议不变，规则命令请求按 `rule-command-trust.md` 收紧 |
| Q11 | 绑定与可达性 | 脚本级绑定引用、时间入口、等待出口与已建立观察；事件事实记录起点/有效期/消费未定义 | 绑定与运行态分离，不继承片段活跃窗口；存储形式按结构评审结论，不以同片段限制替代可达性检查；未定义的事件事实边界登记为精确待评审项，不假设永久有效 |
| Q12 | 实例级挂起 | 到门后声明暂停；同屏其它脚本实例；普通非阻塞观察；多个等待持有来源 | 挂起暂停本实例全部内容推进，不影响其它独立实例；普通观察仍可用；多个持有来源最后一个解除才恢复 |
| Q13 | 规则/片段事实接力 | A 规则成功、A 片段开始/完成作为 B 规则条件；多实例/多执行 | 事实按实例/绑定/执行定位；B 可被 A 的事实启动，不串实例、不用定义级共享布尔 |
| Q14 | 成功≠动作完成 | 判定成功后动作立即提交、延迟未提交、取消 | 成功事实与动作完成事实可区分；已成功结果不因原状态条件之后变假被隐式抹掉；再次确认需显式条件 |
| Q15 | 延迟动作目标 | 成功后延迟到指定片段开始/完成、指定局部时间、明确时间条件/延迟 | 开始与完成是不同语义；动作按声明目标提交，不从零重新判定原始规则 |
| Q16 | 等待与释放源 | 暂停后等待本实例未来片段/内容位置；等待实时时长/外部事实；不可达依赖 | 依赖内容进度前释放相应判定持有或由声明控制保证可达；等待超时不被同一挂起冻结；不可达给诊断，不自动解除/吞规则/强跳主线 |
| Q17 | 时间参照与动作目标分离 | 以 A 片段局部时间/规则成功事实启动 B；B 尚未进入 | 时间参照与动作目标可不同；不要求未进入的 B 先推进自身时间；不把冻结内容位置当作仍会推进 |
| Q18 | 承诺动作与自然完成 | 判定成功后动作延迟未释放；主线采样结束；显式终止实例 | 已承诺动作作为执行依赖参与自然完成，不静默丢弃；等待动作不要求冻结内容推进；显式终止仍回收 |
| Q19 | 规则命令信任边界 | 伪造播放回执、伪造动作引用、跨实例、旧原文包、权限 3/4 命令 | 伪造不产生观看者；请求只解析脚本动作；默认权限 2；EVENT 不受影响 |

| C7 | selector 策略 | 7 调用点 × 6 字段，通用/专属覆盖 | 解析/回落符合 `SelectorSchema` |
| C8 | yaw/pitch/roll/fov/zoom | 角度/线性/几何插值 | 角度最短路径；zoom 几何 |
| C9 | 静态相机 | 无 keyframes | 有 lane、有画面 |
| C10 | morph 实际状态采样 | 交界 10 秒、过渡 3 秒；8.5／11.5 秒处无显式关键帧；A/B 路径与片段效果不同 | 窗口为交界前后各 1.5 秒；各侧按自己的执行位置求实际状态再混合，不直接取末／首关键帧，不重算推进片段效果 |
| C11 | motion/breath 状态所有权 | 各模型、不同 A/B 定义、普通渲染与过渡同帧消费 | 每侧效果归自己的执行状态，每帧只推进一次；过渡只读快照，不采用 next motion／prev breath 拼装规则 |
| C12 | modifier 链 | 多 modifier/优先级/suppress | 全局状态按链；lane 参数保留 |
| C13 | lane 合成 | opacity/dest/source/mask/调色 | 与相机状态同一 t；循环不错位 |
| C14 | 维度 | 同维度/跨维度 | 与 `cross-dimension-camera.md` 一致 |
| C15 | 路径集合／相邻段／切线／offset | 同片段多条路径条目与直线，2／3 轴、顺序无关轴集合、动态参考系、端点联动、offset；绑定目标为位置对象/对象组；相邻判断时混入 FOV/调色关键帧 | 每条绑定只使用自己的控制点；相邻性只在目标位置节点序列内判断；段归属明确、几何互不覆盖；控制点分量可分别调；2D／3D 弧长按各段定义；切线与本段路径同源，不把全片段位置帧强制成组 |
| C16 | 组合与通道级覆盖 | 路径、独立参考系、look_at、其它相机通道、规则与循环组合 | 无语义冲突的能力可组合；look_at 只覆盖负责通道，不排斥位置路径与其它独立通道；不兼容必须给出通道或作用域层面的原因 |

## 八、循环 / 格式清理

| # | 验收项 | 方法 | 通过标准 |
|---|---|---|---|
| L1 | 派生窗口 | 静态有限、无限及等待／分支改变执行路径 | 有限可推导跨度只用于显示／定位；不能由 `start + duration × N` 推定实际已经完成 |
| L2 | 执行位置 | 边界事件、跨执行、暂停恢复 | 当前执行身份与局部位置一致；下一次执行由完成／调度事件建立，无全局时间折叠替代 |
| L3 | pingpong | 正向／反向／边界 | 执行序号决定方向；一次正向／反向各算一次；非视觉轨道拒绝 |
| L4 | 消费／内容事实 | 有限 N、无限、在跑等待与分支、声明时间已过但内容尚在执行 | 次数耗尽且实际执行内容完成才消费；仍有等待／分支不自然结束；无限执行无自然完成点 |
| L5 | 状态策略 | 相机效果、选择器、音频、EVENT、规则绑定 | 按所有权延续或回收；规则每次执行按绑定独立激活，过渡不重复推进相机效果，不一律重置全部状态 |
| L6 | 宏观循环 | 有限／无限、显式循环区间、等待改变执行进度 | 宏观也按执行次数与完成事实推进；区间时间只是定位；服务端 EVENT 既有去重边界不变 |
| L7 | hold_at_end | 有限完成、仍有等待、无限执行 | 有限内容实际完成后保持最终状态；不能到达估计时长就驻留；无限没有自然末端驻留点 |
| L8 | 末端与显示范围 | 无片段、静态有限、含无限、有限内容与无限背景并存 | 有限末端估计与有限部分显示范围分开；含无限表达无有限自然末端；数值哨兵不参与完成判定 |
| L9 | 旧字段 | version/total_duration/keyframes/audio 文件循环旧名 | 全部“已移除”；旧路径逐段迁移为脚本级绑定，不保留全片段隐式控制点复用 |
| L10 | 定位与触点 | FrameDriver／RuleActions／Command／Graph／模板／编辑器 | 无 total_duration 读写；跳转保留目标内容定位／覆盖约束，不因删除总长而放行任意空档 |
| L11 | 无限后的作者编排 | 无限片段后接有限片段，同轨／跨轨及显式顺序依赖 | 不自动截断或拒绝后续声明；独立内容照编排执行；等待无限前置导致不可达属于作者依赖，不冒充框架 terminal 规则 |
