# 曲线集合：脚本级路径条目

> 状态：未实现
> 范围：脚本级曲线集合的归属、定义／绑定、目标片段与相邻端点对、几何与进度、多条目、时间基准
> 关联：`rule-system.md`、`rule-time-gate.md`、`object-model.md`、`schema-and-types.md`、`track-camera.md`、`runtime-evaluation.md`、`migration.md`、`rule-implementation.md`

## 一、摘要

曲线是脚本级独立集合中的声明，与规则集合并列，不是片段元数据、不是 value-only 字段、也不是新轨道。每条曲线先引用一个目标片段，再引用该片段**目标位置节点序列**中的两个相邻关键帧作为段端点，并持有该段几何与段进度。

几何与进度分离：几何 = 三次贝塞尔两个内部控制点（XYZ 可分别编辑，参考空间显式）；进度 = 段内位置如何随局部时间推进。曲线只负责所选轴；未选轴继续按自身采样属性的局部时间／关键帧求值。

**数量口径**：曲线条目不设数量上限；同一片段可以有多条曲线，各自持有自己的端点对与控制点，互不覆盖。

## 二、为什么做

- 现行 `Clip.curve` 是一个片段一份控制点，隐式套到每个位置段：同一片段想给不同段不同曲线、或给同一段并列多条候选路径时，没有承载位置。
- `objects.curve` 前稿把曲线当 value-only 属性，同样表达不了“目标片段 + 相邻关键帧对 + 段几何”。
- 把曲线绑在全片段关键帧总编号上时，FOV／调色等对象增删帧会改变位置曲线端点；端点相邻性必须只在目标位置序列内判断。

## 三、方案

### 3.1 归属

- 曲线集合是**脚本级**的，与 `meta`、`timeline` 并列；不占用 `objects` 的路径键空间，不是新轨道。
- 条目只通过引用定位片段内容，不复制关键帧，不改变片段内部对象与关键帧的归属。
- 集合在解析期建成，播放期只读；脚本替换 = 重建集合。

### 3.2 条目形态

- **曲线定义（CurveDefinition）**：保存两个相邻位置关键帧之间的段几何、控制点参考空间与所选轴；不保存播放进度。
- **曲线绑定（CurveBinding）**：引用目标片段、目标位置对象／对象组，以及该序列中的两个相邻关键帧；一条曲线一个绑定。
- 条目持有目标片段 + 端点引用；重排／插入／删除后必须重映射或报错，不得静默改绑。
- 端点相邻性只在目标位置节点序列内判断，不把 FOV、调色、覆盖层等其它对象的帧拼成全片段总序列。

### 3.3 多条目

- 同一片段可以有多条曲线；每条只负责自己的端点对与所选轴，几何互不覆盖。
- 无曲线的段正常按采样属性插值，不补曲线。
- 插入位置关键帧时，作者可以显式重建／重绑定以产生新几何；不得静默复用旧控制点改变路径。

### 3.4 几何与进度

- 几何：三次贝塞尔两个内部控制点；控制点分量可分别调；参考空间显式（相对段起点／绝对世界轴）。
- 进度：按本次执行局部位置计算，与规则时间门共用同一个 `executionLocalTime`（见 `rule-time-gate.md` §二）。
- 轴集合至少两个、去重、顺序无关；2 轴只保证该平面内 2D 弧长，不承诺 3D 匀速；要整条 3D 路径匀速就选 3 轴。
- 切线由本段路径导数与未选轴的采样属性导数合成；不把全片段位置帧强制成组。

## 四、技术细节

- 加载期编译 `片段 → 曲线条目[]` 索引，运行期不扫全集合。
- 运行时在同一 `executionLocalTime` 采样全部属性；曲线条目按目标片段与端点对求几何／进度，不进 `SampledClip`。
- 曲线条目与规则集合分开承载、分开求值；规则不并入曲线集合，也不改变曲线几何。
- 迁移：旧 clip 级 `curve` 按旧全局关键帧段逐段展开为曲线条目，分别保留端点、控制点、相对／绝对含义与 3D 弧长；不能只把旧一份控制点搬进一条全片段曲线。

## 五、边界

- 相机侧装配（路径与未选轴合成位置、`orient=tangent` 用条目导数）归 `track-camera.md`；本篇只定集合契约。
- 调色曲线（`rgb_curve`、每通道曲线、六条 hue 曲线）与 `transition_curve` 是 value-only 结构或缓动声明，**不属于**本集合。
- 曲线条目不是完成判据，不成为新的总时长来源。
- 序列化／引用表达与稳定片段标识由结构评审定。

## 六、结构评审项（非用户待确认）

- 曲线集合的字段名、序列化与迁移形态。
- 稳定片段引用、端点引用在重排／插入／删除后的表达。
- 多条曲线与同一段并存时的编辑器呈现（归 `../Z-editor/object-model.md`）。
