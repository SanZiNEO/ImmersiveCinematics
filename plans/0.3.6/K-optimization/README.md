# K 轮：优化（编辑器前收尾）

> 状态：未开始
> 定位：**Z 编辑器之前的最后一轮**。只做性能、隔离、技术收口；**不新增脚本语义、不改脚本字段**。

## 二、非目标

- 不改脚本格式、不改相机/过渡/规则语义（这些在 A–J 轮已定）。
- 不做编辑器功能（Z 轮）。
- 不做「感觉更快」的重写：必须有 F5 诊断矩阵或等价可复现测量。
