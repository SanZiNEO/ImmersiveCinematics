> 独立长期讨论文档，不与运动模型文档混写。
> 本文讨论：空间路径有哪些形状、哪些值得加、以及如何用“一键生成关键帧”的方式融入现有模型。

---

## 1. 已确认原则

1. 运动模型保持唯一：路程 ÷ 时间 = 速度，默认匀速
2. 运行时只认：关键帧 + 可选曲线（目前直线 / 三次贝塞尔）
3. 解析型路径（圆、螺旋、正弦、钟摆等）= **生成器**，一键生成普通关键帧/贝塞尔
4. 插值型路径（Catmull-Rom、Hermite 等）= **运行时策略**，直接消费关键帧
5. 两者都不新增第二套运动模型

## 2. 路径形状分类

### 2.1 插值型（消费关键帧）

| 形状 | 是否经过关键帧 | 弧长解析解 | 状态 |
|---|---|---|---|
| 直线 | 是 | 有 | ✅ 已有 |
| 三次贝塞尔 | 仅首尾 | 无 | ✅ 已有（ArcLengthLUT） |
| Catmull-Rom | 全部 | 无 | ❌ 未做 |
| Hermite 三次样条 | 是 | 无 | ❌ 未做 |
| 三次 B 样条 | 否（逼近） | 无 | ❌ 未做 |

### 2.2 解析型（生成器）

| 形状 | 参数 | 生成方式 |
|---|---|---|
| 圆 | 圆心、半径、高度、时长 | 3~4 段贝塞尔 |
| 椭圆 | 圆心、radius_x/z、rotation、高度、时长 | 4 段贝塞尔 |
| 螺旋 | 圆心、半径、圈数、总高、时长 | 圆 + 高度线性，生成关键帧 |
| 8 字（Lissajous） | 两个半径、频率比、时长 | 参数方程采样成关键帧 |
| 正弦波 | 振幅、波长、段数、时长 | 采样成关键帧 |
| 圆弧 | 圆心、半径、起始角、结束角 | 1~n 段贝塞尔 |

## 3. 数学公式（记录用）

### 3.1 三次贝塞尔

\[
B(t) = (1-t)^3P_0 + 3(1-t)^2tP_1 + 3(1-t)t^2P_2 + t^3P_3
\]

### 3.2 Catmull-Rom（一段，P1→P2）

\[
C(t) = c_0t^3 + c_1t^2 + c_2t + c_3
\]

\[
\begin{aligned}
c_0 &= -0.5P_0 + 1.5P_1 - 1.5P_2 + 0.5P_3 \\
c_1 &= P_0 - 2.5P_1 + 2P_2 - 0.5P_3 \\
c_2 &= -0.5P_0 + 0.5P_2 \\
c_3 &= P_1
\end{aligned}
\]

变体：
- uniform：`Δt` 恒定
- chordal：`Δt = |P_{i+1} - P_i|`
- centripetal：`Δt = |P_{i+1} - P_i|^0.5`（最稳，推荐）

### 3.3 Hermite

\[
H(t) = (2t^3 - 3t^2 + 1)P_0 + (t^3 - 2t^2 + t)T_0 + (-2t^3 + 3t^2)P_1 + (t^3 - t^2)T_1
\]

### 3.4 椭圆

\[
x = c_x + a\cos\theta,\quad z = c_z + b\sin\theta
\]

- `a` = X 方向半径
- `b` = Z 方向半径
- 离心率：\(e = \sqrt{1 - b^2/a^2}\)（脚本不直接暴露，UI 可换算）

### 3.5 螺旋

\[
x = c_x + r\cos\theta,\quad y = c_y + h\frac{\theta}{2\pi},\quad z = c_z + r\sin\theta
\]

## 4. 椭圆参数设计（倾向）

| 参数 | 说明 |
|---|---|
| `center_x/y/z` | 中心 |
| `radius_x` | X 方向半径 |
| `radius_z` | Z 方向半径 |
| `rotation` | 椭圆整体旋转角 |
| `height` | 高度 |
| `duration` | 时长 |
| `start_angle` | 起始角度（可选） |
| `direction` | 顺/逆时针（可选） |

不直接用离心率，因为离心率不描述大小。
