# 音频播放模型（Audio Playback Model）：播放者端 + 接收者端双维度

## 一句话定义

把音频空间化抽象成**两个可配置端点**：播放者（音源：位置 + 音量）与接收者（listener：位置 + 是否有效），衰减 = f(音源位置, 接收者位置)。两个端点各自有类型，组合出完整的空间音频语义。

## 现状（已落地，0.3.4 收尾）

- 播放者：`relative`（跟随玩家，无衰减，距离 0 恒定音量）/ `absolute`（世界坐标，空间衰减）
- 接收者：玩家（显式每帧 `alListener3f` = 玩家位置，与 MC SoundEngine 一致）
- 相对模式强制无衰减；衰减仅 absolute 模式生效

## 模型（下版本扩展方向）

### 播放者（音源）位置类型

| 类型 | 位置 | 场景 |
|---|---|---|
| `relative`（跟随玩家） | 玩家位置 + 偏移 | 随身声（现状 ✓） |
| `absolute`（世界坐标） | 固定点 | 场景音（现状 ✓，空间衰减） |
| 跟随实体 | 实体位置 + 偏移 | 声音跟着目标走 |
| 跟随相机 | 相机位置 + 偏移 | 播报/旁白——接收者=相机时恒定 |
| 跟随结构/方块基准 | 结构中心 / 搜索方块 + 偏移 | 复用 0.3.5 基准体系 |

**洞察**：音源位置类型与 0.3.5 的基准体系（player/coordinate/entity/structure/block）同一套枚举——直接复用，不单独设计。

### 接收者（listener）类型

| 类型 | 位置 | 场景 |
|---|---|---|
| 玩家 | 玩家位置（现状） | 默认——MC SoundEngine 同语义 |
| 相机 | 相机位置 | **电影视角**：过场时全部声音以镜头为听者 |
| 关闭/无效 | — | 接收者不存在时音频静音 |

接收者状态 = 位置 + 是否有效（无效 → 静音/暂停）。

## 组合矩阵

```
relative + 接收者玩家 → 距离 0 无衰减（现状 ✓）
absolute + 接收者玩家 → 空间衰减（现状 ✓）
absolute + 接收者相机 → 镜头听远处场景声（下版本，配强加载）
跟随相机 + 接收者相机 → 播报恒定（之前废弃的方案在此组合复活）
```

## 下版本关键难点

**接收者=相机的 listener 接管时机**：
- MC SoundEngine 每帧设 listener=玩家（全局 OpenAL 状态）
- 脚本激活期间接管 listener=相机（电影视角）→ 脚本结束交还玩家
- 影响：接管期间 MC 原版声音也以相机为听者（过场时这是正确语义）
- 时机：渲染回调中每帧覆盖 + 脚本生命周期钩子

## 关联计划

- 相机强加载（`block-based-reference` 同源思路）：接收者=相机时，相机远端区域加载，场景音/区块正常
- 基准体系（`dynamic-yaw-reference` / `block-based-reference`）：音源位置类型复用
- 音频类型选择（sound_source，讨论未落地）：音量跟随玩家可独立控制的类型滑块
