# 0.3.5 六轮任务拆分

> 仅任务拆分，不涉及具体执行。
> 依据：`plans/0.3.5/` 全部设计文档。
>
> **进度**：第 1~5 轮、3.5、5.5、7 已基本完成并提交 · 预加载/相机区域已统一到 `preload-camera-region-unified.md` · 第 6 轮（文档/回归/发布）待做 · 3.5 预加载配置平台持久化未完成 · 5.5 Forge 实体数量偏少待查

## 第 1 轮：低成本独立项 ✅
- 脚本文件夹管理：递归加载子目录 `.json`，编辑器/命令显示相对路径，文档目录约定。
- 触发器前置依赖：触发器 `requires: string[]`（AND），依赖检查前置，validator 提示失效引用。
- 呼吸扰动 v2：废弃白噪声，多类型可选（`perlin` / `perlin_axis` / `sine` / `trauma`），新增 `cam_breath_type/speed`（trauma 另有 `trauma/decay`），`seed` 决定波形形状。
- 输入中间层退出优雅化：退出用 `KeyMapping.setAll()` 重同步键盘 + 鼠标按钮同步 + 清鼠标累积量，覆盖全部退出路径。

## 第 2 轮：基准体系 ✅
- look_at 相对目标：`look_at_target` 对象（绝对/触发点偏移/实体偏移/坐标偏移），兼容旧字段。✅
- 方块搜索基准：`block:<id>[:radius]` 用于 `relative_origin`/`look_at_target`，统一基准解析器。⚠️ 部分
  - `relative_origin`（位置基准）用 block：✅ 已实现
  - **`look_at_target` 用 block（"看向最近方块"）：🔒 留后 / 低优先级**（2026-08-19 裁定：真实需求低，位置用 block + 看目标用实体/坐标/结构已覆盖 99% 场景；`look_at_target` 为自描述 map，留后补向后兼容，成本约半天）
- 动态 yaw 基准：`yaw_base`（world/entity/line），`yaw` 变为相对偏移，与 look_at 互斥。✅（另扩展 `pitch_base` 独立开关 + 基准空间系 `fwd/up/right`，见 `dynamic-yaw-reference.md` 讨论）
- 位置也沿"两点连线"（line）作为 `fwd/up/right` 前轴：🔒 **留后/低优先级**（2026-08-19 裁定：`look_at` × 相对坐标系已可搭配够用，位置沿连线属锦上添花；"方向线"概念已在 `yaw_base=line` 落地，位置侧复用同一 `lineDir` 即可，成本不大）

## 第 3 轮：世界与运镜
- 区块预加载 + 维度字段：scanChunk 磁盘分流、ticket 加载、滑动窗口、区块包补发、clip `dimension` 字段。
- 玩家移动控制：EVENT 关键帧 `position`（x/z），假输入 Mixin 驱动原版移动链路。

## 第 3.5 轮：作者工具与小改动（插在第 4 轮前，集中处理待定小项）
- **触发器动作广播**：`play_script` 加可选 `target`（方案 A）——`player`（默认，现状）/ `all`（全体在线）/ `all_except_trigger`；不做选择器，先三档。
- **区块预加载 scanChunk 磁盘分流 + worldgen 配额**：已生成优先读盘、未生成限速渐进；先确认 `CollectToTag.getResult()` API 再动手。
- **`meta.preload` 逐脚本开关**：默认跟随全局，作者可单脚本关闭。
- **预加载配置平台持久化**：fabric/forge config 接入全部预加载字段（cap/force/prewarm 等）。
- 可选：far 期间抑制 vanilla 玩家区补发日志噪音（`Ignoring chunk ... view range`）。

## 第 4 轮：音频体系
- 听者管理模块：`meta.listener`（player/camera），删除裸 AL 覆盖。
- AUDIO 轨道回归原版 SoundEngine：`CinematicAudioInstance` 重写 + `category` 字段。
- 位置语义：relative 相对听者 + 默认衰减，absolute 世界坐标。
- 环境音重定向：Biome/Underwater/BubbleColumn/animateTick 在 camera 模式采样到相机。
- 编辑器音频联动：repositionAudio/syncToTime/seek/暂停态重写。

## 第 5 轮：编辑器 / 资源 / 预设
- 编辑器交互优化：中间帧继承 + 飞行取景操控模式（F6、WASD/鼠标、记录/取消）。
  - 移动方案参考 Freecam/Zergatul：tick 读 `Options` 键位 + `KeyboardInput.calculateImpulse`，按 yaw 算 forward/right 位移，直接驱动纯 POJO `CameraManager`。
- 编辑器模块化 + 面板重构：Tab 栏独立组件、滚动/触发器命中修复、按模块拆分 Java 文件、预设面板接入。
- Schema Java 元数据化：`schema.json` 迁移为 Java `FieldDef`/`TrackSchemas`/`SchemaRegistry`，编辑器/解析器/默认值共用。
- GIF Overlay：stbi_load_gif 拆帧 + 单帧 DynamicTexture 轮播，内存上限与释放。
- 预设系统：参数 schema + 生成函数注册，初版预设库（环绕轨道等），生成结果可编辑；速度 = 路径长度 ÷ 时长，不单独输入。

## 第 6 轮：文档 / 测试 / 发布
- 文档更新：SCRIPT_FORMAT、AI_SCRIPTING_GUIDE、README、CHANGELOG 覆盖全部新字段与行为变化。
- 全量冒烟/回归：旧脚本兼容、多人、跨维度校验、暂停/重放/打断、编辑器全流程。
- 构建与发布：`gradlew build` 全平台通过，打包 0.3.5 产物。

## 0.3.5 第 7 轮（收尾）：去除 Architectury 第三方引用
- **动机（用户拍板）**：小而精——模组不依赖第三方前置；引入 Arch 后体积 +100~200KB，且实际只用 3 块 API（网络 15 文件 / 事件 2 文件 / 键位注册 / Env 工具）
- **时机与流程（用户拍板）**：第 6 轮文档/回归/发布完成后 → **先创建新分支**（为 0.4.0 多版本铺路）→ 在新分支上开始去 Arch 重构
- **多版本策略**：0.3.x 为功能探索期；**0.4.0 起**按"每个 MC 版本一个分支 + 本方案"做多版本；版本演进靠 AI 同步 + CHANGELOG 详细记录（哪天修了什么 bug）
- **重构方案（参考 VazkiiMods/Neat + Jaredlll08/MultiLoader-Template，已读源码确认）**：
  - `common` 子项目挂 `multiloader-common` + LegacyForge（能编译 MC 类，MCP/Parchment 映射），把源码/资源发布成 `commonJava`/`commonResources` 配置
  - `fabric`：`multiloader-loader` + `fabric-loom`（消费 common 配置；`runs.ideConfigGenerated(true)`）
  - `forge`：`multiloader-loader` + `net.neoforged.moddev.legacyforge`（消费 common 配置；`runs { client/server }`）
  - 各平台自己的 `fabric.mod.json` / `mods.toml`、accessWidener / accessTransformer、入口类
  - 网络/事件/键位：common 定义接口（`CinematicNetwork` / `CinematicEvents`），平台实现（Forge NetworkChannel+事件总线 / Fabric ServerPlayNetworking+Fabric API）
  - 移除 `dev.architectury` 全部 import
- **验收**：全平台 build 通过 + 全量冒烟（网络包/触发/音频/预加载/编辑器）+ 体积对比记录
- **待进一步研究**：MultiLoader-Template 的 `multiloader-common`/`multiloader-loader` 插件源码实现细节，确认后再动手
