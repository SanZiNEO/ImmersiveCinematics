# AUDIO 相对位置模式（讨论点，下个版本决策）

## 背景

AUDIO 轨道的 `relative` 位置模式发生过语义分歧，已修复为"跟随玩家"：

- **旧行为（bug）**：`originPos + 偏移`（激活时刻的玩家位置，固定）→ 音源钉死在激活点，玩家走远 + linear 衰减就听不见
- **当前行为（v2）**：每帧 `玩家当前位置 + 偏移` → 音源跟随玩家

## 讨论点：要不要提供两种模式

| 模式 | 语义 | 典型场景 |
|---|---|---|
| **相对跟随**（当前） | 每帧玩家当前位置 + 偏移，音源始终相对玩家 | 随身音效（脚步/心跳/环境随身）、角色伴音 |
| **相对位置创建**（旧行为） | 激活时刻玩家位置 + 偏移，音源固定在该点 | 场景音（把音频"钉"在激活时的某个相对位置，如洞口风声/远处爆炸），播放期间固定不跟随 |

两种语义都有真实场景：跟随 = 随身声；固定 = 场景声（以激活位置为锚点的"世界坐标"近似）。

## 待定方案（下个版本决策）

1. 给 `position_mode`（音频）加模式值区分两种语义（如 `"relative"`=跟随、`"relative_fixed"`=创建时锚定）
2. 或新增字段（`position_mode: "relative"` + `follow_player: bool`）
3. 或保持单一"跟随"语义（认为场景声应该用 absolute 写世界坐标——但玩家位置运行时才知道，absolute 写不了"我旁边有个洞"）

## 现状结论（0.3.5 已定）

- 保持当前"相对 = 跟随玩家"（已修复、语义干净）
- 两种模式的取舍留到 0.3.5 之后，有真实需求（场景声钉锚）再实现
