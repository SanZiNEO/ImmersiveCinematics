[English Documentation](README.md)

## 这是什么？

ImmersiveCinematics 是一个为整合包设计的过场动画模组。服务端触发系统配合客户端播放，脚本作者通过 JSON 或游戏内编辑器定义过场动画，在指定条件满足时自动播放——共 **23 种触发方式**：登录、位置、进度、群系、击杀、实体/方块/持物交互、维度切换/驻留、合成/使用/消耗/释放/瞬间使用/中断使用物品、拾取/丢弃物品、经验、注视目标、物品栏、结构、游戏阶段。

**适用场景：**
- 进新区域自动播放入场动画
- Boss 战前的剧情展示
- 开宝箱时镜头特写
- 固定机位视角解谜（生化危机0式）
- 自动飞行巡览展示地图

## 功能特性

**过场动画系统**
- 6 自由度相机：位置、偏航、俯仰、滚转、FOV、缩放
- 关键帧驱动 + 贝塞尔曲线路径，流畅镜头运动
- 相对/绝对定位、循环播放、无限时长、相机跟随/注视目标追踪
- 多轨道时间轴：相机、黑边、音频、事件、模组事件、覆盖层（淡入/图片/字幕/画中画）
- 宽银幕遮幅，关键帧驱动宽高比动画
- 镜头间交叉淡化过渡（morph B 模型）

**触发器系统（服务端）**
- 23 种触发类型：登录、位置（点+半径/方体区域）、进度、群系、击杀（含维度/群系/位置场景条件）、实体交互、方块交互、持物交互（物品+目标+目标类型，支持空手）、维度切换、维度驻留、合成物品、使用物品、用完物品、释放物品、瞬间使用、中断使用、拾取物品、丢弃物品、经验（等级/累计值）、注视目标（服务端射线，方块/实体）、物品栏、结构、游戏阶段
- 支持 OR/AND 逻辑和通配符匹配
- 可重复触发或单次触发，支持延迟执行与 on_enter/exit_buffer

**运行时控制**
- 18 项行为标志：可跳过、可打断、末帧保持、键盘/鼠标/生物 AI 屏蔽、7 项独立 HUD 开关、隐藏手臂、视角摇晃抑制、显示玩家模型、暂停时冻结等
- 播放队列：不可打断脚本播放时新请求排队（容量 8、按优先级、自动接播）；可打断脚本被请求立即替换；优先级不能大于打断
- 多玩家脚本追踪与完成状态同步

**兼容性**
- Forge 47.x+ 与 Fabric 1.20.1（MultiLoader，无第三方前置依赖）
- 光影包兼容（不侵入 OpenGL 管线）
- 视角摇晃抑制（受伤抖动、行走摇晃、反胃效果）
- 暂停感知：游戏暂停时脚本自动冻结

**世界与音频**
- 区块预加载 + 远距离相机区域：隐藏假人驱动原版区块/实体追踪，远处运镜场景保持加载，实体中继到真实客户端
- 脚本级预加载开关（`meta.preload`），半径/上限/强制/预热量等配置按平台持久化
- 音频听者模式（`meta.listener`：player/camera）、基于原版 SoundEngine 的 AUDIO 轨道、相对/绝对定位与环境音重定向

## 快速开始

1. 安装 [Minecraft Forge 1.20.1](https://files.minecraftforge.net/net/minecraftforge/forge/index_1.20.1.html)（47.x+）或 Fabric 1.20.1
2. 下载 ImmersiveCinematics 并放入 `.minecraft/mods/`
3. 启动游戏

### 命令

| 命令 | 说明 |
|------|------|
| `/icinematics play <文件> [玩家]` | 播放过场动画脚本（默认全体玩家，支持 `@a`/`@p` 选择器） |
| `/icinematics stop [玩家]` | 停止当前播放 |
| `/icinematics status` | 显示播放状态 |
| `/icinematics reload` | 同步全局脚本到世界存档并重载触发器 |
| `/icinematics validate <文件>` | 脚本静态校验（AI 写脚本后的自查闭环） |

### 游戏内编辑器

使用内置的时间轴编辑器，无需离开游戏即可可视化创建和修改脚本。多轨道时间轴、关键帧编辑、播放控制（播放/暂停单按钮 + 终止归零）、相机三维球、触发器条件编辑器。

单一构建包含播放运行时和游戏内编辑器，所有用户下载同一个 jar 即可。
